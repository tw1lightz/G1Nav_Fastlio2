网络连接调试（mac）：
    打开代理：规则，不要打开虚拟网卡
    mac网络代理打开：sudo ./i.sh

网络ip配置：
    将有线网络与g1连接
    在主机系统上把ip改为和g1相同的123网段
    尝试ping以下几个ip：
        192.168.123.161：运控开发板
        192.168.123.164：二次开发板
        192.168.123.120：livox雷达
    如果能ping通，说明网络配置成功    

ssh连接：
    通过ssh，可以远程登录到g1二次开发板的ubuntu系统
    ssh unitree@192.168.123.164 注意，运控开发板不对外开放，故无法连接
    password：123
    选择（1）foxy
    此时终端变为unitree@ubuntu： 说明登录成功

ROS2通信（主机humble）：
    复制仓库https://github.com/unitreerobotics/unitree_ros2
    安装依赖
    sudo apt install ros-humble-rmw-cyclonedds-cpp
    sudo apt install ros-humble-rosidl-generator-dds-idl
    sudo apt install libyaml-cpp-dev
    下载官方ros2仓库：https://github.com/unitreerobotics/unitree_ros2/tree/master
    不要编译unitree_go，使用ifconfig找到和g1连接的网口名字
    修改setup.sh文件，修改名字（如start.sh）
    打开终端，source start.sh
    然后执行ros2 topic list 能看到成功读取g1的内部话题

点云可视化：
    在终端start.sh启动后，打开rviz，add，by topic，找到livox雷达的cloud话题
    改成point，reliable改成best effort

gazebo仿真：
    参考github项目https://github.com/OpenMind/unitree-sdk
    需要按顺序编译
    在虚拟机运行需要强制令gazebo用软件渲染：export LIBGL_ALWAYS_SOFTWARE=1
    使用的是gazebo ignition

ros2 bag记录数据：
    由于g1导航demo不对外展示建图后的pcd文件，故尝试录制topic信息然后自行处理
    ros2 bag record -o subset /utlidar/cloud_livox /utlidar/imu_livox
