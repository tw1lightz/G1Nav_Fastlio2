# HongTu / Unitree 开发常用命令速查（Linux + Windows）

> 适用场景：本机（Windows/WSL）与远程 Ubuntu（如 `unitree@192.168.100.29`）之间传文件，以及远程主机上复制/移动/删除文件。
>
> 更新时间：2026-01-28

---

## 1. 远程连接

### SSH 登录远程主机
```bash
ssh unitree@192.168.100.29
```

---

## 2. 本机 ⇄ 远程 传输（走 SSH 通道）

### 2.1 scp：简单好用（文件/目录）
**本机 → 远程（传文件）**
```bash
scp <本地文件> unitree@192.168.100.29:/home/unitree/HongTu/
```

**本机 → 远程（传目录）**（目录一定要加 `-r`）
```bash
scp -r <本地目录> unitree@192.168.100.29:/home/unitree/HongTu/
```
scp -r "D:\G1_dev\unitree_cpp-master" unitree@192.168.100.18:/home/unitree/
**远程 → 本机（拉文件）**
```bash
scp unitree@192.168.100.29:/home/unitree/HongTu/<文件> <本地目录>(.代表拉到当前终端路径)
```

**远程 → 本机（拉目录）**
```bash
scp -r unitree@192.168.100.29:/home/unitree/HongTu/<目录> <本地目录>
```

**常见报错 & 解释**
- `not a regular file`：你传的是**目录/特殊文件**，`scp` 默认只传文件，需要 `-r`。
- 远程目录不存在：先在远程 `mkdir -p /home/unitree/HongTu`

---

### 2.2 rsync：更稳（断点续传/增量/带进度）
> 大文件、多文件、网络不稳时更推荐。

**本机 → 远程**
```bash
rsync -avh --progress <本地路径> unitree@192.168.100.29:/home/unitree/HongTu/
```

**远程 → 本机**
```bash
rsync -avh --progress unitree@192.168.100.29:/home/unitree/HongTu/<路径> <本地目录>
```

## 3. 远程主机上：查看 / 复制 / 移动 / 删除（Linux）

### 3.1 ls：列出文件（查看“有什么”）
```bash
ls
ls -lah
```
- `-l`：详细信息
- `-a`：包含隐藏文件
- `-h`：可读大小（KB/MB/GB）

---

### 3.2 cp：复制（copy）
**复制文件**
```bash
cp a.txt /目标目录/
cp a.txt /目标目录/b.txt    # 同时改名
```

**复制目录（必须加 -r）**
```bash
cp -r mydir/ /目标目录/
```

**复制并尽量保留权限/时间戳/软链接（推荐）**
```bash
cp -a mydir/ /目标目录/
```

**只复制目录里的内容到目标（不带外层目录名）**
```bash
cp -a mydir/. /目标目录/
```

**常见报错 & 解释**
- `cp: -r not specified; omitting directory 'xxx'`：你在复制目录，但没加 `-r`（或用 `-a`）。

---

### 3.3 mv：移动/重命名（move，等价于“剪切粘贴”）
**移动文件**
```bash
mv a.txt /目标目录/
```

**移动目录**
```bash
mv mydir/ ~/
```

**移动并改名**
```bash
mv a.txt /目标目录/newname.txt
mv mydir/ ~/newdir
```

**防止覆盖（提示确认）**
```bash
mv -i a.txt /目标目录/
```

---

### 3.4 rm：删除（remove）
**删除文件**
```bash
rm a.txt
```

**删除目录（连同里面所有内容）**
```bash
rm -r mydir/
```

**删除前逐个确认（更安全）**
```bash
rm -ri mydir/
```

**强制删除（危险：不提示）**
```bash
rm -rf mydir/
```

**常见报错 & 解释**
- `rm: cannot remove 'xxx': Is a directory`：你要删的是目录，需要 `rm -r`（或别删目录）。

## 4. 你这次项目的“直接可用模板”

### 4.1 把本机目录传到远程（解决 scp 目录报错）
（Windows PowerShell 示例）
```powershell
scp -r "D:\G1_dev\HongTu\cyclonedds-releases-0.10.x" unitree@192.168.100.29:/home/unitree/HongTu/
```

### 4.2 在远程把目录移动到主目录（~）
（你在 `~/HongTu` 里）
```bash
mv cyclonedds-releases-0.10.x ~/
```

### 4.3 删除文件 vs 删除目录
**删文件**
```bash
rm /root/HongTu/g1_control.py
```

**删目录**
```bash
rm -r /root/HongTu/unitree_sdk2_python/example/g1/high_level
```

### 4.4 把 `g1.py` 移到 `high_level` 目录
```bash
mv /root/HongTu/g1.py /root/HongTu/unitree_sdk2_python/example/g1/high_level/
```
（不确定位置时，先确认）
```bash
pwd
ls -lah g1.py
ls -lah /root/HongTu/unitree_sdk2_python/example/g1/high_level/
```

## 5. 快捷键（复制/粘贴“命令文本”）

> 这是复制粘贴**文字**，不是文件。

- Windows Terminal / PowerShell：复制 `Ctrl+Shift+C`，粘贴 `Ctrl+Shift+V`（有时也支持 `Ctrl+V`）
- Linux GNOME Terminal：复制 `Ctrl+Shift+C`，粘贴 `Ctrl+Shift+V`

---

## 6. 安全提醒（强烈建议）
- 删除前先 `ls -lah` 看清楚路径。
- 能用 `rm -ri` 就先用 `rm -ri`，确认后再删。
- `rm -rf /` 这类命令千万别手滑（高危）。
